HAMNA SALEEM — PINEGROW EDITABLE PORTFOLIO

This is the same portfolio design, prepared so it is easier to edit visually in Pinegrow.

OPEN IN PINEGROW
1. Open Pinegrow.
2. Choose Open Project / Open Folder.
3. Select the folder: Hamna_Pinegrow_Portfolio
4. Open index.html.

WHAT TO EDIT
- Text: click/select the text element in Pinegrow and edit it.
- Images: each project image is in the assets folder. Replace the image source in the Properties panel.
- Colours, fonts and spacing: edit styles.css visually through Pinegrow's CSS/Style panels.
- Resume: replace Hamna_Saleem_Resume.pdf with a newer file using the same filename, or update the link.
- Navigation: section IDs are About, Capabilities, Projects, Experience, Growth and Contact.

SECTION LABELS
The page includes clear editor labels for:
Top Navigation
Hero / Introduction
About
Capabilities
Selected Projects
Experience & Research
Leadership, Service & Future Orientation

Footer

PUBLISHING TO YOUR EXISTING GITHUB SITE
When finished editing, upload the updated index.html, styles.css, assets folder and resume PDF to the same GitHub repository. Because this version now uses styles.css, make sure styles.css is uploaded too.

IMPORTANT
Do not rename the assets folder unless you also update the image paths in index.html.
